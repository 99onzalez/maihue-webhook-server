PASOS RÁPIDOS (30 min)
================================================================================

1. GITHUB (5 min)
   ☐ Crear repositorio "maihue-webhook-server"
   ☐ Clonar
   ☐ Copiar archivos
   ☐ git add . && git commit && git push

2. RAILWAY DEPLOY (10 min)
   ☐ Railway → New → GitHub Repo
   ☐ Seleccionar maihue-webhook-server
   ☐ Click Deploy
   ☐ Esperar a que termine (✅ status)

3. VARIABLES (5 min)
   ☐ Railway → Servicio → Variables
   ☐ Agregar todas las variables de arriba
   ☐ Click Save

4. AUDIO (3 min)
   ☐ Railway → Volumes → New Volume
   ☐ Name: audios
   ☐ Mount: /app/audios
   ☐ Upload: audio_pdo_gerardo.aac

5. TEST (7 min)
   ☐ Health check → debe retornar status online
   ☐ Send message → debe recibir SMS
   ☐ Send audio → debe recibir audio después 120s

================================================================================
ERRORES COMUNES
================================================================================

502 Bad Gateway
  → Servidor aún se está desplegando
  → Esperar 5 minutos

Cannot connect to Redis
  → Verificar REDIS_HOST=redis en Variables

Evolution API Error
  → Verificar EVOLUTION_API_KEY
  → Verificar INSTANCE_ID
  → Verificar que Evolution esté online

Audio not found
  → Verificar ruta: /app/audios/audio_pdo_gerardo.aac
  → Verificar que volumen está montado

Round Robin no funciona
  → Verificar Redis está online
  → GET /debug/round-robin debe retornar estado
